Descripción del proyecto

Este proyecto presenta el diseño conceptual de una base de datos
para la red social estudiantil Pascualina.

El modelo permite representar la información de los estudiantes,
sus publicaciones, grupos, eventos e intereses, además de las
relaciones existentes entre estos elementos.
